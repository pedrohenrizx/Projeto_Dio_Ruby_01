# 💎 Projeto 01 - DIO Ruby Developer

Projeto desenvolvido como parte do bootcamp/formação de **Ruby** na plataforma da [Digital Innovation One (DIO)](https://www.dio.me/).

---

## 📌 Sobre o Desafio

O objetivo deste primeiro projeto prático é aplicar os conceitos fundamentais da linguagem **Ruby**, tais como:
- Entrada e saída padrão de dados (`gets`, `puts`, `print`);
- Manipulação de tipos primitivos (Strings, Inteiros/Floats);
- Interpolação e formatação de dados;
- Estruturação básica de scripts executáveis em Ruby (`projeto01.rb`).

## 🚀 Pré-requisitos

Para executar o script, você precisará ter o **Ruby** instalado no seu ambiente de desenvolvimento.

Verifique se o Ruby está instalado executando no terminal:

```bash
ruby -v
```

> Recomendado: Ruby 3.0 ou superior. Caso precise instalar, visite a documentação oficial em [ruby-lang.org](https://www.ruby-lang.org/pt/downloads/).

---

## 💻 Como Executar o Projeto

1. Clone este repositório ou faça o download dos arquivos:
   ```bash
   git clone https://github.com/SEU_USUARIO/Projeto_Dio_Ruby_01.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd Projeto_Dio_Ruby_01
   ```

3. Execute o script Ruby pelo terminal:
   ```bash
   ruby projeto01.rb
   ```

4. Siga as instruções exibidas na tela para interagir com o programa via terminal.
